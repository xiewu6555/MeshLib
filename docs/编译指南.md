## 概述

MeshLib 采用现代 CMake 构建系统，支持模块化编译和多种配置选项。本指南提供从源代码编译 MeshLib 的完整流程。

### 构建系统特点

- **现代 CMake**：使用 CMake 3.16+ 的目标导向构建
- **vcpkg 集成**：自动依赖管理
- **模块化设计**：可选择性编译所需模块
- **并行编译**：支持多核心加速编译
- **Unity Build**：可选的编译加速技术
- **自动 DLL 管理**：Windows 平台自动拷贝运行时依赖

## 快速开始

### 一键编译脚本

对于标准配置，使用提供的快速编译脚本：

```batch
:: Windows - 完整编译（包含 OpenCASCADE）
build_with_manual_occt.bat
```

脚本内容：
```batch
@echo off
echo ========================================
echo MeshLib 快速编译脚本
echo 使用手动安装的 OpenCASCADE
echo ========================================

:: 设置项目根目录
set MESHLIB_ROOT=%~dp0
cd /d %MESHLIB_ROOT%

:: 初始化 vcpkg（如果需要）
if not exist "vcpkg\vcpkg.exe" (
    echo 初始化 vcpkg...
    call setup-vcpkg.bat
)

:: 创建构建目录
if not exist "build_final" mkdir build_final
cd build_final

:: 配置项目
echo 配置 CMake 项目...
cmake .. -G "Visual Studio 17 2022" -A x64 ^
    -DUSE_MANUAL_OPENCASCADE=ON ^
    -DCMAKE_BUILD_TYPE=Release

:: 编译项目
echo 开始编译...
cmake --build . --config Release --parallel 8

echo ========================================
echo 编译完成！
echo 可执行文件位置：%MESHLIB_ROOT%build_final\bin\
echo ========================================
pause
```

### 最简编译步骤

如果您已完成环境配置，最简单的编译步骤：

```cmd
# 1. 进入项目目录
cd F:\Code\OpenProject\MeshLib

# 2. 初始化 vcpkg（仅首次需要）
setup-vcpkg.bat

# 3. 创建并进入构建目录
mkdir build && cd build

# 4. 配置 CMake
cmake .. -G "Visual Studio 17 2022" -A x64 -DUSE_MANUAL_OPENCASCADE=ON

# 5. 编译
cmake --build . --config Release

# 6. 运行
cd bin
MeshViewer.exe
```

## 详细编译步骤

### 步骤 1：准备源代码

```cmd
# 克隆仓库
git clone https://github.com/MeshLib/MeshLib.git
cd MeshLib

# 更新子模块
git submodule update --init --recursive

# 切换到稳定分支（可选）
git checkout master
```

### 步骤 2：安装依赖

#### 自动安装（推荐）

```cmd
# Windows
setup-vcpkg.bat

# 脚本会自动：
# 1. 克隆 vcpkg 到本地
# 2. Bootstrap vcpkg
# 3. 安装 vcpkg.json 中定义的所有依赖
```

#### 手动安装依赖

```cmd
# 使用项目本地 vcpkg
.\vcpkg\vcpkg.exe install --triplet x64-windows

# 或指定特定包
.\vcpkg\vcpkg.exe install `
    boost-algorithm:x64-windows `
    eigen3:x64-windows `
    tbb:x64-windows `
    libe57format:x64-windows `
    gdcm:x64-windows
```

### 步骤 3：配置 CMake

#### 基础配置

```cmd
mkdir build
cd build

# Visual Studio 2022 生成器
cmake .. -G "Visual Studio 17 2022" -A x64
```

#### 高级配置选项

```cmd
cmake .. -G "Visual Studio 17 2022" -A x64 ^
    -DUSE_MANUAL_OPENCASCADE=ON ^
    -DCMAKE_BUILD_TYPE=Release ^
    -DMR_CXX_STANDARD=20 ^
    -DBUILD_TESTING=ON ^
    -DBUILD_PYTHON_BINDINGS=ON ^
    -DBUILD_DOTNET_BINDINGS=ON ^
    -DENABLE_CUDA=OFF ^
    -DCMAKE_INSTALL_PREFIX=F:\MeshLib_Install
```

### 步骤 4：编译项目

#### 命令行编译

```cmd
# Release 版本（推荐）
cmake --build . --config Release --parallel 8

# Debug 版本（用于开发调试）
cmake --build . --config Debug --parallel 8

# 指定目标
cmake --build . --config Release --target MeshViewer
```

#### Visual Studio IDE 编译

1. 打开生成的 `MeshLib.sln`
2. 选择配置（Release/Debug）
3. 选择平台（x64）
4. 生成解决方案（Ctrl+Shift+B）

### 步骤 5：验证编译结果

```cmd
# 检查输出目录
dir build\bin\*.exe
dir build\bin\*.dll

# 运行主程序
cd build\bin
MeshViewer.exe

# 检查版本信息
MeshViewer.exe --version
```

## 构建配置选项

### CMake 选项说明

| 选项 | 默认值 | 说明 |
|------|--------|------|
| `USE_MANUAL_OPENCASCADE` | OFF | 使用手动安装的 OpenCASCADE |
| `BUILD_TESTING` | OFF | 构建单元测试 |
| `BUILD_PYTHON_BINDINGS` | OFF | 构建 Python 绑定 |
| `BUILD_DOTNET_BINDINGS` | OFF | 构建 .NET/C# 绑定 |
| `BUILD_C_BINDINGS` | ON | 构建 C 语言绑定 |
| `ENABLE_CUDA` | OFF | 启用 CUDA GPU 加速 |
| `MR_CXX_STANDARD` | 20 | C++ 标准版本（20 或 23） |
| `CMAKE_BUILD_TYPE` | Release | 构建类型（Debug/Release/RelWithDebInfo） |
| `BUILD_SHARED_LIBS` | ON | 构建动态链接库 |
| `CMAKE_UNITY_BUILD` | OFF | 启用 Unity Build 加速编译 |

### 预设配置

项目提供了预定义的 CMake 预设（CMakePresets.json）：

```json
{
  "version": 3,
  "configurePresets": [
    {
      "name": "windows-release",
      "displayName": "Windows Release",
      "generator": "Visual Studio 17 2022",
      "architecture": "x64",
      "cacheVariables": {
        "CMAKE_BUILD_TYPE": "Release",
        "USE_MANUAL_OPENCASCADE": "ON"
      }
    },
    {
      "name": "windows-debug",
      "displayName": "Windows Debug",
      "inherits": "windows-release",
      "cacheVariables": {
        "CMAKE_BUILD_TYPE": "Debug"
      }
    }
  ]
}
```

使用预设：
```cmd
# 使用预设配置
cmake --preset windows-release

# 构建
cmake --build --preset windows-release
```

## 部署与打包

### 创建安装包

```cmd
# 配置安装路径
cmake .. -DCMAKE_INSTALL_PREFIX=F:\MeshLib_Install

# 构建并安装
cmake --build . --config Release --target INSTALL

# 目录结构
# F:\MeshLib_Install\
# ├── bin\          # 可执行文件和 DLL
# ├── lib\          # 库文件
# ├── include\      # 头文件
# └── share\        # 资源文件
```

### 创建便携版

创建脚本 `create_portable.bat`：

```batch
@echo off
set OUTPUT_DIR=MeshLib_Portable
set BUILD_DIR=build_final\bin

echo 创建便携版 MeshLib...

:: 创建目录结构
mkdir %OUTPUT_DIR%
mkdir %OUTPUT_DIR%\bin
mkdir %OUTPUT_DIR%\plugins
mkdir %OUTPUT_DIR%\resources

:: 拷贝可执行文件
xcopy /y %BUILD_DIR%\*.exe %OUTPUT_DIR%\bin\
xcopy /y %BUILD_DIR%\*.dll %OUTPUT_DIR%\bin\

:: 拷贝插件
xcopy /y /s %BUILD_DIR%\plugins\* %OUTPUT_DIR%\plugins\

:: 拷贝资源
xcopy /y /s resources\* %OUTPUT_DIR%\resources\

:: 创建启动脚本
echo @echo off > %OUTPUT_DIR%\MeshViewer.bat
echo cd /d %%~dp0 >> %OUTPUT_DIR%\MeshViewer.bat
echo start bin\MeshViewer.exe %%* >> %OUTPUT_DIR%\MeshViewer.bat

echo 便携版创建完成：%OUTPUT_DIR%
```

### Docker 镜像

```dockerfile
# Dockerfile
FROM mcr.microsoft.com/windows/servercore:ltsc2022

# 安装 Visual C++ 运行时
ADD https://aka.ms/vs/17/release/vc_redist.x64.exe /vc_redist.x64.exe
RUN /vc_redist.x64.exe /quiet /install

# 拷贝 MeshLib
COPY build_final/bin /app/bin
COPY resources /app/resources

WORKDIR /app/bin
ENTRYPOINT ["MeshViewer.exe"]
```

构建 Docker 镜像：
```cmd
docker build -t meshlib:latest .
docker run -it meshlib:latest
```

## 性能优化

### 编译时优化

#### 1. Unity Build
```cmd
# 启用 Unity Build 加速编译
cmake .. -DCMAKE_UNITY_BUILD=ON -DCMAKE_UNITY_BUILD_BATCH_SIZE=16
```

#### 2. 预编译头
```cmake
# 在 CMakeLists.txt 中配置
target_precompile_headers(MRMesh
    PRIVATE
    <vector>
    <memory>
    <algorithm>
    "MRMesh/MRMesh.h"
)
```

#### 3. 并行编译
```cmd
# 使用所有 CPU 核心
cmake --build . --config Release --parallel

# 限制并行任务数
cmake --build . --config Release --parallel 8
```

#### 4. 链接时优化（LTO）
```cmd
cmake .. -DCMAKE_INTERPROCEDURAL_OPTIMIZATION=ON
```

### 运行时优化

#### 1. 编译器优化标志
```cmake
# 在 CMakeLists.txt 中添加
if(MSVC)
    target_compile_options(MRMesh PRIVATE
        /O2      # 最大优化
        /GL      # 整体程序优化
        /fp:fast # 快速浮点模型
        /arch:AVX2 # 使用 AVX2 指令集
    )
endif()
```

#### 2. Profile-Guided Optimization (PGO)
```cmd
# 步骤 1：仪表化构建
cmake .. -DCMAKE_CXX_FLAGS="/GL"
cmake --build . --config Release

# 步骤 2：运行典型工作负载
cd build\bin
MeshViewer.exe --benchmark

# 步骤 3：优化构建
cmake --build . --config Release -- /LTCG:PGO
```

## 故障排除

### 常见编译错误

#### 1. 找不到依赖库

**错误信息**：
```
CMake Error: Could not find a package configuration file provided by "Eigen3"
```

**解决方案**：
```cmd
# 确保 vcpkg 已安装依赖
.\vcpkg\vcpkg.exe install eigen3:x64-windows

# 重新配置 CMake
cmake .. -DCMAKE_TOOLCHAIN_FILE=.\vcpkg\scripts\buildsystems\vcpkg.cmake
```

#### 2. OpenCASCADE 链接错误

**错误信息**：
```
LINK : fatal error LNK1104: cannot open file 'TKernel.lib'
```

**解决方案**：
```cmd
# 使用手动安装的 OpenCASCADE
cmake .. -DUSE_MANUAL_OPENCASCADE=ON

# 或禁用 OpenCASCADE 支持
cmake .. -DMESHLIB_BUILD_MRCADTOOLS=OFF
```

#### 3. DLL 加载失败

**错误信息**：
```
系统错误：找不到指定的模块 VCRUNTIME140.dll
```

**解决方案**：
1. 安装 Visual C++ Redistributable：
   ```cmd
   # 下载并安装
   https://aka.ms/vs/17/release/vc_redist.x64.exe
   ```

2. 确保 DLL 拷贝脚本运行：
   ```cmd
   cmake --build . --config Release --target CopyRuntimeDependencies
   ```

#### 4. 内存不足

**错误信息**：
```
fatal error C1060: compiler is out of heap space
```

**解决方案**：
```cmd
# 减少并行编译数
cmake --build . --config Release --parallel 4

# 或禁用 Unity Build
cmake .. -DCMAKE_UNITY_BUILD=OFF
```

#### 5. Python 绑定编译失败

**错误信息**：
```
Could not find Python3 (missing: Python3_INCLUDE_DIRS)
```

**解决方案**：
```cmd
# 指定 Python 路径
cmake .. -DPython3_ROOT_DIR=C:\Python311

# 或使用 vcpkg Python
.\vcpkg\vcpkg.exe install python3:x64-windows
```

## 持续集成配置

### GitHub Actions 示例

```yaml
# .github/workflows/build.yml
name: Build MeshLib

on: [push, pull_request]

jobs:
  build-windows:
    runs-on: windows-latest
    
    steps:
    - uses: actions/checkout@v3
      with:
        submodules: recursive
    
    - name: Setup vcpkg
      run: |
        git clone https://github.com/Microsoft/vcpkg.git
        .\vcpkg\bootstrap-vcpkg.bat
        .\vcpkg\vcpkg.exe integrate install
    
    - name: Install dependencies
      run: |
        .\vcpkg\vcpkg.exe install --triplet x64-windows
    
    - name: Configure
      run: |
        cmake -B build -G "Visual Studio 17 2022" -A x64 `
          -DCMAKE_TOOLCHAIN_FILE=vcpkg\scripts\buildsystems\vcpkg.cmake `
          -DUSE_MANUAL_OPENCASCADE=ON
    
    - name: Build
      run: cmake --build build --config Release --parallel
    
    - name: Test
      run: ctest --test-dir build -C Release --output-on-failure
    
    - name: Upload artifacts
      uses: actions/upload-artifact@v3
      with:
        name: meshlib-windows
        path: build\bin\
```
