## 概述

MeshLib 是一个功能强大的开源 3D 数据处理 SDK，支持多种编程语言绑定和跨平台部署。本指南将帮助您在 Windows 平台上配置完整的开发环境。

### 主要特性
- 高级网格处理算法（布尔运算、孔洞填补、简化等）
- 支持 C++、Python、C# 多语言绑定
- GPU 加速支持（通过 CUDA）
- 丰富的文件格式支持（包括 STEP、E57、DICOM 等）
- 现代化的 CMake 构建系统
- 独立的项目级 vcpkg 依赖管理

## 系统要求

### 最低配置
- **操作系统**：Windows 10 1903 (10.0.18362) 或更高版本
- **处理器**：支持 AVX 指令集的 x64 处理器
- **内存**：8GB RAM（推荐 16GB 或更高）
- **硬盘空间**：至少 20GB 可用空间（包含依赖和构建产物）
- **显卡**：支持 OpenGL 3.3 或更高版本

### 推荐配置
- **操作系统**：Windows 11 或 Windows 10 22H2
- **处理器**：Intel Core i7 或 AMD Ryzen 7 及以上
- **内存**：32GB RAM
- **硬盘空间**：50GB SSD 空间
- **显卡**：NVIDIA GPU（支持 CUDA 11.4+）用于 GPU 加速

## 开发工具安装

### 1. Visual Studio 2022

MeshLib 需要 Visual Studio 2022 进行 Windows 平台开发。

#### 安装步骤：

1. **下载 Visual Studio 2022**
   - 访问 [Visual Studio 下载页面](https://visualstudio.microsoft.com/downloads/)
   - 选择 Community、Professional 或 Enterprise 版本

2. **选择工作负载**
   
   必需的工作负载：
   - ✅ **使用 C++ 的桌面开发**
   - ✅ **.NET 桌面开发**（如需 C# 支持）
   - ✅ **Python 开发**（如需 Python 绑定）

3. **选择单独组件**
   
   确保安装以下组件：
   - ✅ MSVC v143 - VS 2022 C++ x64/x86 生成工具
   - ✅ Windows 10 SDK (10.0.22621.0) 或更高版本
   - ✅ CMake 的 C++ 工具
   - ✅ 用于 Windows 的 C++ Clang 工具（可选）
   - ✅ Git for Windows

4. **完成安装**
   - 安装大小约 10-15GB
   - 重启计算机以确保所有环境变量生效

### 2. CMake

虽然 Visual Studio 自带 CMake，但建议安装独立版本以获得更好的命令行支持。

#### 安装步骤：

1. **下载 CMake**
   - 访问 [CMake 官网](https://cmake.org/download/)
   - 下载 Windows x64 Installer（推荐版本 3.27 或更高）

2. **安装配置**
   - 运行安装程序
   - 选择 "Add CMake to the system PATH for all users"
   - 完成安装

3. **验证安装**
   ```cmd
   cmake --version
   # 应显示：cmake version 3.27.x 或更高
   ```

### 3. Git

用于版本控制和子模块管理。

#### 安装步骤：

1. **下载 Git**
   - 访问 [Git 官网](https://git-scm.com/download/win)
   - 下载 64-bit Git for Windows Setup

2. **安装配置**
   - 使用默认设置即可
   - 确保选择 "Git from the command line and also from 3rd-party software"

3. **配置 Git**
   ```cmd
   git config --global user.name "Your Name"
   git config --global user.email "your.email@example.com"
   git config --global core.autocrlf true
   ```

### 4. Python（可选）

如需 Python 绑定支持，安装 Python 3.8 或更高版本。

#### 安装步骤：

1. **下载 Python**
   - 访问 [Python 官网](https://www.python.org/downloads/)
   - 下载 Python 3.11 或 3.12（推荐）

2. **安装配置**
   - ✅ 勾选 "Add Python to PATH"
   - 选择 "Customize installation"
   - ✅ 勾选所有可选功能
   - 安装位置建议：`C:\Python311` 或 `C:\Python312`

3. **安装必需的 Python 包**
   ```cmd
   pip install --upgrade pip
   pip install numpy pytest black isort pre-commit
   ```

### 5. CUDA Toolkit（可选）

如需 GPU 加速支持，安装 NVIDIA CUDA Toolkit。

#### 安装步骤：

1. **检查 GPU 兼容性**
   - 确保有 NVIDIA GPU（计算能力 3.5 或更高）
   - 更新 NVIDIA 显卡驱动到最新版本

2. **下载 CUDA Toolkit**
   - 访问 [NVIDIA CUDA 下载](https://developer.nvidia.com/cuda-downloads)
   - 选择 CUDA Toolkit 11.4 或更高版本

3. **安装配置**
   - 使用默认安装路径：`C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.4\`
   - 安装完成后验证：
   ```cmd
   nvcc --version
   ```

## 依赖管理环境配置

### vcpkg 项目级配置

MeshLib 采用项目独立的 vcpkg 配置，避免全局环境污染。

#### 自动初始化（推荐）

1. **克隆 MeshLib 仓库**
   ```cmd
   git clone https://github.com/MeshLib/MeshLib.git
   cd MeshLib
   git submodule update --init --recursive
   ```

2. **运行自动配置脚本**
   ```cmd
   # Windows 命令提示符或 PowerShell
   setup-vcpkg.bat
   ```

   脚本将自动完成以下操作：
   - 克隆 vcpkg 到 `./vcpkg` 目录
   - 执行 vcpkg bootstrap
   - 配置项目专用的 triplet
   - 安装基础依赖

3. **验证配置**
   ```cmd
   .\vcpkg\vcpkg.exe version
   # 应显示 vcpkg 版本信息
   ```

#### 手动配置（高级用户）

如果自动脚本失败，可以手动配置：

1. **克隆 vcpkg**
   ```cmd
   git clone https://github.com/Microsoft/vcpkg.git
   cd vcpkg
   ```

2. **Bootstrap vcpkg**
   ```cmd
   .\bootstrap-vcpkg.bat
   ```

3. **创建项目 triplet**
   
   创建文件 `vcpkg/triplets/community/x64-windows-meshlib.cmake`：
   ```cmake
   set(VCPKG_TARGET_ARCHITECTURE x64)
   set(VCPKG_CRT_LINKAGE dynamic)
   set(VCPKG_LIBRARY_LINKAGE dynamic)
   set(VCPKG_BUILD_TYPE release)
   
   # Windows 特定设置
   if(PORT MATCHES "opencascade")
       set(VCPKG_BUILD_TYPE "release")
   endif()
   ```

4. **设置环境变量**（可选）
   ```cmd
   setx VCPKG_ROOT "F:\Code\OpenProject\MeshLib\vcpkg"
   ```

## 特殊依赖配置

### OpenCASCADE 配置

由于 vcpkg 中的 OpenCASCADE 可能存在编译问题，MeshLib 支持手动安装预编译版本。

#### 手动安装 OpenCASCADE 7.9.1

1. **下载预编译版本**
   - 访问 [OpenCASCADE 官网](https://old.opencascade.com/content/previous-releases)
   - 下载 OpenCASCADE 7.9.1 Windows 64-bit 预编译版本
   - 或使用直接链接：`opencascade-7.9.1-vc14-64.zip`

2. **解压到指定目录**
   ```cmd
   # 创建目录结构
   mkdir F:\Code\OpenProject\MeshLib\thirdparty\opencascade
   
   # 解压到以下路径
   # F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64\
   ```

3. **验证目录结构**
   ```
   thirdparty/opencascade/occt_vc14-64/
   ├── win64/
   │   ├── vc14/
   │   │   ├── bin/    # DLL 文件
   │   │   ├── lib/    # 库文件
   │   │   └── inc/    # 头文件
   ```

4. **配置环境变量**（可选）
   ```cmd
   setx OPENCASCADE_ROOT "F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64"
   ```

### GDCM（DICOM 支持）

GDCM 用于支持医学影像 DICOM 格式，通过 vcpkg 自动安装。

```cmd
# 如果需要单独安装
.\vcpkg\vcpkg.exe install gdcm:x64-windows
```

### E57 格式支持

E57 格式支持通过 libe57format 和 xerces-c 提供：

```cmd
# 如果需要单独安装
.\vcpkg\vcpkg.exe install libe57format:x64-windows xerces-c:x64-windows
```

## 环境变量设置

### 必需的环境变量

创建批处理文件 `set_meshlib_env.bat`：

```batch
@echo off
echo 设置 MeshLib 开发环境变量...

:: 项目根目录
set MESHLIB_ROOT=F:\Code\OpenProject\MeshLib

:: vcpkg 配置
set VCPKG_ROOT=%MESHLIB_ROOT%\vcpkg
set VCPKG_DEFAULT_TRIPLET=x64-windows

:: OpenCASCADE 配置（如果使用手动安装）
set OPENCASCADE_ROOT=%MESHLIB_ROOT%\thirdparty\opencascade\occt_vc14-64
set PATH=%OPENCASCADE_ROOT%\win64\vc14\bin;%PATH%

:: CUDA 配置（如果安装了 CUDA）
set CUDA_PATH=C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.4
set PATH=%CUDA_PATH%\bin;%PATH%

:: CMake 和构建工具
set CMAKE_PREFIX_PATH=%VCPKG_ROOT%\installed\x64-windows
set PATH=%MESHLIB_ROOT%\build_final\bin;%PATH%

echo 环境变量设置完成！
```

### 永久设置环境变量

使用系统设置永久添加环境变量：

1. 打开 "系统属性" → "高级系统设置"
2. 点击 "环境变量"
3. 在 "系统变量" 中添加：
   - `MESHLIB_ROOT`: `F:\Code\OpenProject\MeshLib`
   - `VCPKG_ROOT`: `F:\Code\OpenProject\MeshLib\vcpkg`
   - `OPENCASCADE_ROOT`: `F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64`

## 常见问题

### Q1: vcpkg 安装包失败

**问题**：vcpkg install 命令失败，提示网络错误或编译错误。

**解决方案**：
1. 检查网络代理设置
2. 清理 vcpkg 缓存：
   ```cmd
   .\vcpkg\vcpkg.exe remove --outdated
   rmdir /s /q .\vcpkg\buildtrees
   rmdir /s /q .\vcpkg\packages
   ```
3. 使用二进制缓存：
   ```cmd
   set VCPKG_BINARY_SOURCES=clear;files,F:\vcpkg-cache,readwrite
   ```

### Q2: OpenCASCADE 链接错误

**问题**：编译时提示找不到 OpenCASCADE 库。

**解决方案**：
1. 确认使用手动安装的 OpenCASCADE：
   ```cmd
   cmake .. -DUSE_MANUAL_OPENCASCADE=ON
   ```
2. 检查路径是否正确：
   ```cmd
   dir F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64\win64\vc14\lib
   ```

### Q3: DLL 缺失错误

**问题**：运行 MeshViewer.exe 时提示缺少 DLL。

**解决方案**：
1. 确保构建配置中启用了 DLL 拷贝：
   - 检查 `cmake/Modules/CopyRuntimeDependencies.cmake` 存在
2. 手动拷贝 DLL（如果自动拷贝失败）：
   ```cmd
   xcopy /y /s ".\vcpkg\installed\x64-windows\bin\*.dll" ".\build_final\bin\"
   xcopy /y /s ".\thirdparty\opencascade\occt_vc14-64\win64\vc14\bin\*.dll" ".\build_final\bin\"
   ```

### Q4: Python 绑定编译失败

**问题**：构建 Python 绑定时失败。

**解决方案**：
1. 确保 Python 开发头文件已安装
2. 使用 vcpkg 提供的 Python：
   ```cmd
   .\vcpkg\vcpkg.exe install python3:x64-windows
   ```
3. 在 CMake 中指定 Python 路径：
   ```cmd
   cmake .. -DPython3_ROOT_DIR=%VCPKG_ROOT%\installed\x64-windows
   ```

### Q5: 内存不足错误

**问题**：编译大型项目时出现内存不足。

**解决方案**：
1. 增加虚拟内存（页面文件）大小
2. 使用并行编译限制：
   ```cmd
   cmake --build . --config Release -j 4
   ```
3. 关闭其他占用内存的程序
