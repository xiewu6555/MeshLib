## 依赖相关问题

### 🔴 E57Format.dll 和 Xerces-C DLL 缺失

**问题描述**：
运行 MeshViewer.exe 时提示找不到 E57Format.dll 或 xerces-c_3_2.dll。

**错误信息**：
```
系统错误：找不到指定的模块 E57Format.dll
The code execution cannot proceed because xerces-c_3_2.dll was not found
```

**根本原因**：
- vcpkg.json 中未包含 libe57format 和 xerces-c 依赖
- DLL 文件未正确拷贝到输出目录

**解决方案**：

1. **更新 vcpkg.json**：
```json
{
  "dependencies": [
    // ... 其他依赖
    "libe57format",
    "xerces-c",
    // ...
  ]
}
```

2. **重新安装依赖**：
```cmd
.\vcpkg\vcpkg.exe install libe57format:x64-windows xerces-c:x64-windows
```

3. **验证安装**：
```cmd
dir .\vcpkg\installed\x64-windows\bin\*e57*.dll
dir .\vcpkg\installed\x64-windows\bin\*xerces*.dll
```

4. **确保 DLL 拷贝**：
检查 `cmake/Modules/CopyRuntimeDependencies.cmake` 包含：
```cmake
file(GLOB E57_DLLS "${VCPKG_INSTALLED_DIR}/${VCPKG_TARGET_TRIPLET}/bin/*E57*.dll")
file(GLOB XERCES_DLLS "${VCPKG_INSTALLED_DIR}/${VCPKG_TARGET_TRIPLET}/bin/*xerces*.dll")
```

**预防措施**：
- 定期运行 `vcpkg upgrade` 更新依赖
- 使用 `vcpkg list` 验证已安装的包

### 🔴 OpenCASCADE vcpkg 编译失败

**问题描述**：
通过 vcpkg 安装 OpenCASCADE 时，gettext-libintl 编译失败。

**错误信息**：
```
error: building gettext-libintl:x64-windows failed with: BUILD_FAILED
error: while installing OpenCASCADE dependencies
```

**根本原因**：
- vcpkg 中的 OpenCASCADE 包依赖复杂
- gettext-libintl 在 Windows 上的编译问题
- vcpkg 版本与 OpenCASCADE 不兼容

**完整解决方案**：

#### 方案 A：使用预编译的 OpenCASCADE（推荐）

1. **下载 OpenCASCADE 7.9.1**：
   - 访问：https://old.opencascade.com/content/previous-releases
   - 下载：opencascade-7.9.1-vc14-64.zip (约 200MB)

2. **解压到指定目录**：
```cmd
:: 创建目录
mkdir F:\Code\OpenProject\MeshLib\thirdparty\opencascade

:: 解压文件（使用 7-Zip 或 Windows 自带解压）
:: 目标路径：F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64\
```

3. **创建 CMake 配置模块**：

创建 `cmake/Modules/UseManualOpenCASCADE.cmake`：
```cmake
# UseManualOpenCASCADE.cmake
# 配置手动安装的 OpenCASCADE

if(NOT USE_MANUAL_OPENCASCADE)
    return()
endif()

message(STATUS "Using manually installed OpenCASCADE")

# 设置 OpenCASCADE 根目录
set(OPENCASCADE_ROOT "${CMAKE_SOURCE_DIR}/thirdparty/opencascade/occt_vc14-64")

if(NOT EXISTS "${OPENCASCADE_ROOT}")
    message(FATAL_ERROR "OpenCASCADE not found at ${OPENCASCADE_ROOT}")
endif()

# 设置路径
set(OpenCASCADE_INCLUDE_DIR "${OPENCASCADE_ROOT}/inc")
set(OpenCASCADE_LIBRARY_DIR "${OPENCASCADE_ROOT}/win64/vc14/lib")
set(OpenCASCADE_BINARY_DIR "${OPENCASCADE_ROOT}/win64/vc14/bin")

# 创建 OpenCASCADE 目标
add_library(OpenCASCADE::OpenCASCADE INTERFACE IMPORTED)

# 设置包含目录
target_include_directories(OpenCASCADE::OpenCASCADE INTERFACE
    ${OpenCASCADE_INCLUDE_DIR}
)

# 查找所有库文件
file(GLOB OpenCASCADE_LIBRARIES "${OpenCASCADE_LIBRARY_DIR}/*.lib")

# 链接库
target_link_libraries(OpenCASCADE::OpenCASCADE INTERFACE
    ${OpenCASCADE_LIBRARIES}
)

# 设置 OpenCASCADE_FOUND
set(OpenCASCADE_FOUND TRUE)

# 拷贝 DLL 文件
if(WIN32)
    file(GLOB OpenCASCADE_DLLS "${OpenCASCADE_BINARY_DIR}/*.dll")
    set(OPENCASCADE_RUNTIME_DLLS ${OpenCASCADE_DLLS} CACHE INTERNAL "")
endif()

message(STATUS "OpenCASCADE configured successfully")
message(STATUS "  Include: ${OpenCASCADE_INCLUDE_DIR}")
message(STATUS "  Libraries: ${OpenCASCADE_LIBRARY_DIR}")
message(STATUS "  Binaries: ${OpenCASCADE_BINARY_DIR}")
```

4. **更新主 CMakeLists.txt**：
```cmake
# 在 find_package 调用之前添加
option(USE_MANUAL_OPENCASCADE "Use manually installed OpenCASCADE" ON)

if(USE_MANUAL_OPENCASCADE)
    include(UseManualOpenCASCADE)
else()
    find_package(OpenCASCADE REQUIRED)
endif()
```

5. **编译时使用**：
```cmd
cmake .. -G "Visual Studio 17 2022" -A x64 -DUSE_MANUAL_OPENCASCADE=ON
```

#### 方案 B：修复 vcpkg 编译问题

1. **更新 vcpkg**：
```cmd
cd vcpkg
git pull
.\bootstrap-vcpkg.bat
```

2. **使用特定版本的 baseline**：
```json
// vcpkg.json
{
  "builtin-baseline": "10b7a178346f3f0abef60cecd5130e295afd8da4"
}
```

3. **手动安装依赖**：
```cmd
.\vcpkg\vcpkg.exe install gettext:x64-windows --recurse
.\vcpkg\vcpkg.exe install opencascade:x64-windows
```

**验证 OpenCASCADE 安装**：
```cmd
:: 检查头文件
dir F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64\inc\*.hxx

:: 检查库文件
dir F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64\win64\vc14\lib\TK*.lib

:: 检查 DLL
dir F:\Code\OpenProject\MeshLib\thirdparty\opencascade\occt_vc14-64\win64\vc14\bin\TK*.dll
```

### 🔴 GDCM 依赖问题（MRVoxels 模块）

**问题描述**：
编译 MRVoxels 模块时找不到 GDCM 库，无法支持 DICOM 格式。

**错误信息**：
```
CMake Error: Could not find GDCM
fatal error C1083: Cannot open include file: 'gdcmReader.h'
```

**解决方案**：

1. **添加 GDCM 到 vcpkg.json**：
```json
{
  "dependencies": [
    // ... 其他依赖
    "gdcm",
    // ...
  ]
}
```

2. **安装 GDCM**：
```cmd
.\vcpkg\vcpkg.exe install gdcm:x64-windows
```

3. **验证安装**：
```cmd
:: 检查安装的文件
dir .\vcpkg\installed\x64-windows\include\gdcm-3.0\*.h
dir .\vcpkg\installed\x64-windows\lib\gdcm*.lib
dir .\vcpkg\installed\x64-windows\bin\gdcm*.dll
```

4. **CMake 配置**：
```cmake
# 在 MRVoxels/CMakeLists.txt 中
find_package(GDCM REQUIRED)
target_link_libraries(MRVoxels PRIVATE
    gdcmCommon
    gdcmDICT
    gdcmDSED
    gdcmIOD
    gdcmMSFF
)
```

**注意事项**：
- GDCM 3.0.24 需要较新的 C++ 编译器
- 确保 Windows SDK 版本 >= 10.0.18362

### 🟡 DLL 依赖自动拷贝问题

**问题描述**：
编译成功但运行时找不到依赖的 DLL 文件。

**解决方案**：

创建 `cmake/Modules/CopyRuntimeDependencies.cmake`：

```cmake
# CopyRuntimeDependencies.cmake
# 自动拷贝运行时依赖的 DLL 文件

function(copy_runtime_dependencies TARGET_NAME)
    if(NOT WIN32)
        return()
    endif()
    
    # 获取 vcpkg 安装目录
    if(DEFINED ENV{VCPKG_ROOT})
        set(VCPKG_INSTALLED_DIR "$ENV{VCPKG_ROOT}/installed")
    else()
        set(VCPKG_INSTALLED_DIR "${CMAKE_SOURCE_DIR}/vcpkg/installed")
    endif()
    
    # 获取目标输出目录
    set(OUTPUT_DIR $<TARGET_FILE_DIR:${TARGET_NAME}>)
    
    # 收集所有 DLL 文件
    set(ALL_DLLS)
    
    # vcpkg DLLs
    file(GLOB VCPKG_DLLS 
        "${VCPKG_INSTALLED_DIR}/${VCPKG_TARGET_TRIPLET}/bin/*.dll"
    )
    list(APPEND ALL_DLLS ${VCPKG_DLLS})
    
    # OpenCASCADE DLLs（如果使用手动安装）
    if(USE_MANUAL_OPENCASCADE AND DEFINED OPENCASCADE_RUNTIME_DLLS)
        list(APPEND ALL_DLLS ${OPENCASCADE_RUNTIME_DLLS})
    endif()
    
    # CUDA DLLs（如果启用）
    if(ENABLE_CUDA AND CUDAToolkit_FOUND)
        file(GLOB CUDA_DLLS 
            "${CUDAToolkit_BIN_DIR}/*.dll"
        )
        list(APPEND ALL_DLLS ${CUDA_DLLS})
    endif()
    
    # 创建自定义命令拷贝 DLL
    foreach(DLL ${ALL_DLLS})
        add_custom_command(TARGET ${TARGET_NAME} POST_BUILD
            COMMAND ${CMAKE_COMMAND} -E copy_if_different
            "${DLL}"
            "${OUTPUT_DIR}"
            COMMENT "Copying ${DLL} to output directory"
        )
    endforeach()
    
    # 统计信息
    list(LENGTH ALL_DLLS DLL_COUNT)
    message(STATUS "Configured ${DLL_COUNT} DLLs to copy for ${TARGET_NAME}")
endfunction()

# 创建独立的拷贝目标
function(create_copy_dlls_target)
    add_custom_target(CopyRuntimeDependencies ALL
        COMMENT "Copying runtime dependencies..."
    )
    
    # Windows 特定
    if(WIN32)
        # 使用 PowerShell 脚本进行批量拷贝
        file(WRITE "${CMAKE_BINARY_DIR}/copy_dlls.ps1" "
            \$ErrorActionPreference = 'SilentlyContinue'
            \$OutputDir = '${CMAKE_RUNTIME_OUTPUT_DIRECTORY}'
            
            # Create output directory
            New-Item -ItemType Directory -Force -Path \$OutputDir
            
            # Copy vcpkg DLLs
            Copy-Item '${VCPKG_INSTALLED_DIR}/${VCPKG_TARGET_TRIPLET}/bin/*.dll' -Destination \$OutputDir -Force
            
            # Copy OpenCASCADE DLLs
            if('${USE_MANUAL_OPENCASCADE}' -eq 'ON') {
                Copy-Item '${OPENCASCADE_BINARY_DIR}/*.dll' -Destination \$OutputDir -Force
            }
            
            Write-Host 'DLL copy completed'
        ")
        
        add_custom_command(TARGET CopyRuntimeDependencies
            COMMAND powershell -ExecutionPolicy Bypass -File "${CMAKE_BINARY_DIR}/copy_dlls.ps1"
        )
    endif()
endfunction()
```

使用方法：
```cmake
# 在主 CMakeLists.txt 中
include(CopyRuntimeDependencies)

# 为主程序配置 DLL 拷贝
copy_runtime_dependencies(MeshViewer)

# 或创建独立的拷贝目标
create_copy_dlls_target()
```

## 编译错误解决

### 🔴 C++ 标准版本不兼容

**问题描述**：
编译时出现 C++ 语言特性相关的错误。

**错误信息**：
```
error C2429: language feature 'requires-clause' requires compiler flag '/std:c++20'
```

**解决方案**：

1. **设置 C++ 标准**：
```cmake
# CMakeLists.txt
set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 或通过命令行
cmake .. -DMR_CXX_STANDARD=20
```

2. **Visual Studio 设置**：
- 项目属性 → C/C++ → 语言
- C++ 语言标准：ISO C++20 标准

---

### 🔴 链接错误 LNK2019

**问题描述**：
链接时找不到符号定义。

**错误信息**：
```
error LNK2019: unresolved external symbol "public: __cdecl MR::Mesh::Mesh(void)"
```

**常见原因和解决方案**：

1. **缺少库链接**：
```cmake
target_link_libraries(YourTarget PRIVATE
    MRMesh
    MRViewer
    # 添加缺失的库
)
```

2. **导出宏问题**：
```cpp
// 确保使用正确的导出宏
class MRMESH_API Mesh {
    // ...
};
```

3. **库构建顺序**：
```cmake
# 确保依赖顺序正确
add_subdirectory(MRMesh)
add_subdirectory(MRViewer)  # 依赖 MRMesh
```

---

### 🟡 预编译头错误

**问题描述**：
预编译头相关的编译错误。

**错误信息**：
```
fatal error C1010: unexpected end of file while looking for precompiled header
```

**解决方案**：

1. **禁用预编译头**：
```cmake
set_target_properties(YourTarget PROPERTIES
    COMPILE_FLAGS "/Y-"
)
```

2. **正确配置预编译头**：
```cmake
target_precompile_headers(YourTarget
    PRIVATE
    "pch.h"
)
```

## 运行时问题

### 🔴 程序启动失败

**问题描述**：
MeshViewer.exe 无法启动或立即崩溃。

**诊断步骤**：

1. **检查 DLL 依赖**：
```cmd
:: 使用 Dependencies Walker 替代工具
dumpbin /dependents MeshViewer.exe

:: 或使用 PowerShell
[System.Reflection.Assembly]::LoadFile("F:\path\to\MeshViewer.exe").GetReferencedAssemblies()
```

2. **启用详细日志**：
```cmd
set MESHLIB_LOG_LEVEL=DEBUG
MeshViewer.exe --verbose
```

3. **检查 OpenGL 支持**：
```cmd
:: 运行 OpenGL 诊断
MeshViewer.exe --opengl-info
```

**常见解决方案**：

1. **安装 Visual C++ Redistributable**：
```cmd
:: 下载并安装最新版本
https://aka.ms/vs/17/release/vc_redist.x64.exe
```

2. **更新显卡驱动**：
- NVIDIA：https://www.nvidia.com/drivers
- AMD：https://www.amd.com/support
- Intel：https://www.intel.com/content/www/us/en/support

3. **设置兼容模式**：
- 右键 MeshViewer.exe → 属性 → 兼容性
- 勾选"以兼容模式运行"
- 选择 Windows 10

## 性能问题

### 🟡 编译速度慢

**问题描述**：
项目编译时间过长。

**优化方案**：

1. **使用并行编译**：
```cmd
:: 使用所有 CPU 核心
cmake --build . --config Release --parallel

:: MSBuild 并行
msbuild MeshLib.sln /p:Configuration=Release /m
```

2. **启用 Unity Build**：
```cmake
set(CMAKE_UNITY_BUILD ON)
set(CMAKE_UNITY_BUILD_BATCH_SIZE 16)
```

3. **使用 ccache（Windows 上使用 clcache）**：
```cmd
pip install clcache
set CC=clcache
set CXX=clcache
```

4. **增量链接**：
```cmake
set(CMAKE_EXE_LINKER_FLAGS "${CMAKE_EXE_LINKER_FLAGS} /INCREMENTAL")
```

**问题描述**：
程序运行缓慢或响应迟钝。

**诊断和优化**：

1. **性能分析**：
```cmd
:: Visual Studio Performance Profiler
devenv /Profile MeshViewer.exe
```

```cmake
# Release 模式优化
set(CMAKE_CXX_FLAGS_RELEASE "/O2 /Ob2 /DNDEBUG")

if(MSVC)
    set(CMAKE_CXX_FLAGS "${CMAKE_CXX_FLAGS} /arch:AVX2")

3. **GPU 加速**：

# 启用 CUDA
set(ENABLE_CUDA ON)
set(CMAKE_CUDA_ARCHITECTURES "75;86")
```

## 平台特定问题

### Windows 特定

#### 🟡 长路径问题

**问题描述**：
Windows 上路径超过 260 字符限制。

**解决方案**：

1. **启用长路径支持**：
```cmd
:: 管理员权限运行
reg add "HKLM\SYSTEM\CurrentControlSet\Control\FileSystem" /v LongPathsEnabled /t REG_DWORD /d 1 /f
```

2. **使用短路径**：
```cmd
:: 获取短路径名
for %I in ("F:\Very Long Path Name\MeshLib") do echo %~sI
```

#### 🟡 权限问题

**问题描述**：
无法写入或访问某些目录。

**解决方案**：

1. **以管理员身份运行**：
```cmd
:: 创建管理员快捷方式
powershell Start-Process cmd -Verb runAs
```

2. **修改目录权限**：
```cmd
icacls "F:\Code\OpenProject\MeshLib" /grant Everyone:F /T
```
